# Phoenix Tech Refresh

Corporate website and future client portal for **Phoenix Tech Refresh**, an enterprise IT asset disposition (ITAD), remarketing, data-destruction, reverse-logistics, recycling, and value-recovery company.

## Project goals

- Present Phoenix Tech Refresh as an enterprise-grade, security- and compliance-oriented technology lifecycle partner.
- Generate qualified RFQ / quote-request leads from IT, procurement, finance, sustainability, and compliance stakeholders.
- Differentiate the company from commodity e-waste recyclers through value recovery, remarketing, secure logistics, reporting, and circular-economy outcomes.
- Support a future authenticated client portal for asset tracking, certificates, recovered-value reporting, ESG reporting, and service requests.
- Meet modern enterprise expectations for accessibility, performance, SEO, security, and maintainability.

## Current phase

**Phase 0 — Discovery, brand direction, information architecture, and technical planning.**

The visual identity and homepage design are still being refined. Production frontend implementation will begin after the design direction is approved.

- Next.js + React + TypeScript

- Structured SEO / schema markup

- Core Web Vitals target: LCP < 2.5s, INP < 200ms, CLS < 0.1

## Design direction

The brand should feel **clean, confident, institutional, secure, precise, and modern**—closer to strong cybersecurity, financial-services, and logistics brands than to a local recycling company. The Phoenix name refers to the company’s location and does not require a literal phoenix-bird mark.
