# Content and Asset Inputs

This checklist identifies the business-owned material needed to build the site without inventing or publishing unverified claims.

## Brand

- Final vector logo files
- Horizontal / stacked / icon-only variants
- Approved color palette
- Typography selections / licenses if applicable
- Brand usage rules

## Company

- Approved company description
- Company history / story
- Leadership names, titles, bios, and headshots
- Approved company statistics
- Years in business
- Employee count if public
- Annual asset / unit volume if public
- Facility square footage if public
- Public facility addresses
- Service coverage map / regions
- Business hours
- Main phone / email

## Services

For each service, confirm:

- Scope
- Eligible asset types
- Minimum volumes where applicable
- Service geography
- Typical workflow
- Typical timeline
- Reporting deliverables
- Onsite / offsite options
- Logistics options
- Pricing / quote model if public

## Compliance and security

Only publish verified items.

- Current certification list
- Current certificate PDFs
- Certification logo usage rights
- Audit cadence / history approved for public use
- NIST 800-88 process language
- Data-destruction methods actually offered
- Insurance limits / descriptions approved for public use
- Downstream-vendor policy
- Export / landfill policy language
- HIPAA / GLBA / FACTA / FERPA alignment language reviewed by compliance / legal

## Remarketing and value recovery

- Testing / grading process
- Refurbishment capabilities
- Resale channels that can be described publicly
- Buyback / revenue-share model
- Payment timeline
- Example recovered-value reporting
- Approved recovered-value case studies

## Sustainability / ESG

- Landfill-diversion methodology
- Units refurbished vs. recycled
- E-waste processed
- Carbon / emissions methodology if used
- Circularity reporting methodology
- Sample client impact report
- Environmental claims reviewed for substantiation

## Case studies

Target 3–5 launch-ready stories.

For each:

- Client industry
- Client name or anonymization requirement
- Problem / scope
- Asset volume and types
- Locations
- Timeline
- Services delivered
- Quantified business outcome
- Quantified recovered value where approved
- Environmental outcome where approved
- Client quote / approval

## Photography / media

Preferred authentic imagery:

- Facility exterior / interior
- Secure intake
- Asset scanning / serialization
- Testing and grading
- Data destruction
- Server / data-center work
- Secure logistics
- Warehouse / pallet movement
- Refurbishment
- Team / leadership

Record usage rights and model releases where needed.

## Resources

Launch content candidates:

- Enterprise ITAD vendor evaluation checklist
- Data-destruction compliance guide
- IT asset remarketing guide
- Data-center decommissioning checklist
- ESG / circularity guide
- ITAD glossary
- Frequently asked questions

## Careers

- Culture copy
- Benefits copy
- EEO statement
- ATS platform
- Open-role feed / integration access

## Legal

Counsel-reviewed content:

- Privacy Policy
- Terms of Service
- Accessibility Statement
- Cookie Policy
- State privacy / consent requirements

## Integrations

- CRM platform
- Marketing automation platform
- ATS
- Analytics platform
- Heatmap / session-replay decision
- Live-chat decision
- Internal asset-tracking / ERP platform
- API documentation
- SSO / IdP requirements

## Approval rule

If a claim, certification, metric, customer logo, case-study result, compliance statement, environmental claim, or insurance statement is not verified, the website should use a clearly marked content placeholder in development rather than publish the claim.
