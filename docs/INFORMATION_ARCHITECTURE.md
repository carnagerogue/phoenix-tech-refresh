## Homepage content sequence

The homepage should be designed as a conversion and trust narrative, not a generic service-card landing page.

1. **Hero** — concise enterprise value proposition + Request a Quote + Learn How It Works
2. **Trust / proof** — approved certifications, scale indicators, client proof, or quantified outcomes
3. **What Phoenix Tech Refresh does** — lifecycle story spanning secure collection through reuse / remarketing / responsible recycling
4. **Enterprise services** — focused service navigation
5. **Value recovery** — make remarketing and economic recovery a co-equal differentiator
6. **Security and compliance** — chain of custody, data handling, auditability, certificates
7. **Process** — Assess / Collect / Process / Report / Remarket or Recycle
8. **Industries** — industry pathways with relevant risk framing
9. **Sustainability / circularity** — approved impact data and reuse-first story
10. **Case study / proof** — quantified result when approved content is available
11. **Resources** — compliance/procurement-oriented insights and guides
12. **Final CTA** — quote request

## Service-page template

Every core service page should include:

- Clear service definition
- Buyer problem / risk
- Phoenix Tech Refresh approach
- Process steps
- Chain-of-custody / compliance angle where relevant
- Asset types / project types supported
- Reporting / deliverables
- Related services
- Relevant industry proof
- Primary CTA

## Industry-page template

Every industry page should include:

- Industry-specific operational risks
- Regulatory / security considerations
- Relevant Phoenix Tech Refresh services
- Process or chain-of-custody explanation
- Case study or proof where available
- Downloadable checklist / guide opportunity
- Quote / consultation CTA

## UX rules

- Any service or compliance detail should be reachable within three clicks from the homepage.
- Navigation should prioritize buyer intent over internal company terminology.
- Mobile navigation and forms are first-class requirements.
- The site should clearly distinguish public marketing pages from the authenticated portal experience.
